タグ作成コマンド
注釈付き版(annotated,正式)
git tag -a [タグ名] -m"[メッセージ]"

軽量版(lightweight)
git tag [タグ名]

後付けも可
git tag [タグ名] [コミット名]

タグデータの表示
git show [タグ名]

seina_miura@PW0041 MINGW64 /c/sadopj_workspace/Git/git_tutorial (master)
