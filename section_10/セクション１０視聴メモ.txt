避難させた作業を復元

git stash apply
ステージごと復元
git stash apply --index

特定の作業を復元
git stash apply [スタッシュ名]

66
避難させた作業を削除

最新の作業を削除
git stash drop


特定の作業を削除
git stash drop [スタッシュ名]

すべての作業を削除
git stash clear
